# Automatic Blood Pressure Monitor Hardware Plan

Этот документ описывает вариант доработки текущего прототипа HealthSaver до
автоматического тонометра.

Текущая база:

- ESP32 с датчиком давления `XGZP6847A`.
- Пневматическая линия через распределитель.
- Ручной нагнетатель воздуха.
- Стрелочный манометр в `mmHg` для контроля и калибровки.
- Передача измерений с датчика на хаб по BLE.

Цель доработки:

- заменить ручную накачку электрическим насосом;
- добавить манжету;
- добавить управляемый сброс воздуха;
- обеспечить питание ESP32/датчика от 5 В, а насоса и клапана от 12 В;
- сохранить возможность измерять давление через `XGZP6847A`;
- сделать систему достаточно безопасной для учебного прототипа.

## Важное ограничение

Такая схема является прототипом, а не сертифицированным медицинским прибором.
Для реального использования на человеке обязательно нужны:

- аппаратное ограничение максимального давления;
- аварийный ручной сброс воздуха;
- программный лимит давления;
- тестирование на стенде до тестирования на человеке;
- проверка показаний по эталонному манометру или готовому тонометру.

Для первых испытаний лучше использовать бутылку/резервуар, манометр и манжету,
а не руку человека.

## Лучший практический вариант

Самый надежный путь - взять пневматическую часть от готового автоматического
тонометра:

- манжету;
- насос;
- клапан сброса;
- трубки;
- штуцеры;
- возможно, корпус и разъем манжеты.

Электронику и алгоритм можно оставить своими: ESP32, `XGZP6847A`, BLE и сервер.

Причина: у тонометров уже подобраны насос, клапан, манжета и пневматика. Это
сильно снижает риск, что отдельно купленный насос будет слишком слабым,
слишком шумным, слишком быстрым или несовместимым по трубкам.

## Пневматическая схема

```text
12V pump
  |
  | -> optional check valve
  |
  +---- T ---- cuff
       |
       +---- XGZP6847A pressure sensor
       |
       +---- 12V normally closed solenoid valve ---- throttle ---- atmosphere
       |
       +---- manual emergency dump valve ---- atmosphere
```

Назначение элементов:

- `pump` - накачивает манжету.
- `cuff` - манжета на руку.
- `XGZP6847A` - измеряет давление в общей пневматической линии.
- `solenoid valve` - открывается для сброса воздуха.
- `throttle` - ограничивает скорость сброса, чтобы давление падало плавно.
- `manual emergency dump valve` - ручной аварийный сброс, не зависящий от ESP32.
- `optional check valve` - обратный клапан, если насос пропускает воздух назад.

Для осциллометрического измерения важно, чтобы сброс был плавным. Типичная
цель - примерно `2-3 mmHg/s`. При слишком быстром сбросе данные будут хуже, при
слишком медленном измерение станет долгим и неудобным.

## Электрическая схема

Насос и клапан нельзя подключать напрямую к GPIO ESP32. Их нужно включать через
MOSFET-ключи.

```text
12V+ -> pump+
pump- -> MOSFET drain
MOSFET source -> GND

12V+ -> valve+
valve- -> MOSFET drain
MOSFET source -> GND

ESP32 GPIO -> 100-220 Ohm -> MOSFET gate
MOSFET gate -> 10 kOhm -> GND

flyback diode across pump
flyback diode across valve

12V GND == ESP32 GND
```

Для ESP32:

```text
12V supply -> buck converter 12V to 5V -> ESP32 5V/VIN
ESP32 3.3V -> XGZP6847A, если модуль датчика рассчитан на 3.3V
```

Общая земля обязательна: минус блока 12 В, минус понижающего преобразователя и
GND ESP32 должны быть соединены.

### От чего питается ESP32

ESP32 питается не от MOSFET и не от GPIO. В автономной схеме она питается от
того же блока `12 В`, что и насос с клапаном, но через понижающий
преобразователь `12 В -> 5 В`.

Подключение:

```text
+12 В блока питания -> IN+ buck converter
GND блока питания   -> IN- buck converter

OUT+ buck converter -> 5V/VIN ESP32
OUT- buck converter -> GND ESP32
```

Итоговая схема питания:

```text
Блок питания 12 В
   |
   +-> насос и клапан по линии +12 В
   |
   +-> buck converter 12 В -> 5 В -> ESP32 5V/VIN
```

При отладке ESP32 может временно питаться от USB компьютера. Но для автономной
версии тонометра лучше питать ESP32 от понижающего преобразователя, чтобы вся
система включалась от одного блока питания `12 В`.

Датчик давления обычно питается от ESP32:

```text
ESP32 3.3V -> VCC XGZP6847A
ESP32 GND  -> GND XGZP6847A / общая GND-шина
```

Перед подключением датчика нужно проверить, на какое питание рассчитан
конкретный модуль `XGZP6847A`: `3.3 В` или `5 В`.

### Что такое MOSFET-ключ

MOSFET-ключ в этой схеме - это электронный выключатель. ESP32 подает на него
маленький управляющий сигнал `3.3 В`, а MOSFET уже включает или выключает
более мощную нагрузку на `12 В`: насос или клапан.

GPIO ESP32 нельзя использовать как питание для насоса или клапана. Пин ESP32
может управлять только затвором MOSFET (`gate`), а ток насоса или клапана идет
от блока питания `12 В` через саму нагрузку и MOSFET.

Для насоса:

```text
12V -> pump+ -> pump- -> MOSFET drain -> MOSFET source -> GND
```

Для клапана:

```text
+12V -> valve+ -> valve- -> MOSFET drain -> MOSFET source -> GND
```

Управление от ESP32:

```text
ESP32 GPIO -> 100-220 Ohm -> MOSFET gate
MOSFET gate -> 10 kOhm -> GND
```

Резистор `100-220 Ohm` ставится последовательно между GPIO и `gate`. Резистор
`10 kOhm` ставится между `gate` и GND, чтобы MOSFET оставался выключенным, пока
ESP32 загружается или GPIO еще не настроен.

### Как сделать общий GND, если на ESP32 мало GND-пинов

Не нужно подключать все провода напрямую к GND-пинам ESP32. GND-пины ESP32
нужны только для соединения ESP32 с общей землей схемы.

Сделайте отдельную общую GND-шину. Это может быть:

- синяя/минусовая линия на макетной плате breadboard;
- винтовая клеммная колодка;
- WAGO-клемма;
- отдельная дорожка на перфоплате;
- просто аккуратно спаянная общая точка для прототипа.

К этой GND-шине подключаются:

```text
GND блока питания 12 В
GND понижающего преобразователя 12 В -> 5 В
GND ESP32
MOSFET source насоса
MOSFET source клапана
нижний вывод резистора 10 kOhm насоса
нижний вывод резистора 10 kOhm клапана
GND датчика XGZP6847A
```

То есть ESP32 не должна быть "разветвителем земли" для всей схемы. Достаточно
одним проводом соединить любой GND-пин ESP32 с общей GND-шиной.

Пример общей земли:

```text
                 общая GND-шина
                       |
        +--------------+--------------+--------------+
        |              |              |              |
      ESP32 GND      12V GND       MOSFET S       sensor GND
                                      |
                            source насоса/клапана
```

### Куда подключить MOSFET физически

Для одного MOSFET, который управляет насосом:

```text
Плюс блока 12 В         -> pump+
pump-                  -> drain MOSFET
source MOSFET          -> общая GND-шина
GPIO ESP32             -> резистор 100-220 Ohm -> gate MOSFET
gate MOSFET            -> резистор 10 kOhm -> общая GND-шина
GND ESP32              -> общая GND-шина
```

Для второго MOSFET, который управляет клапаном, схема такая же:

```text
Плюс блока 12 В         -> valve+
valve-                 -> drain MOSFET
source MOSFET          -> общая GND-шина
другой GPIO ESP32      -> резистор 100-220 Ohm -> gate MOSFET
gate MOSFET            -> резистор 10 kOhm -> общая GND-шина
GND ESP32              -> общая GND-шина
```

Например:

```text
GPIO25 -> MOSFET насоса
GPIO26 -> MOSFET клапана
```

Пины `3.3V` и `5V/VIN` на ESP32 не используются для питания насоса или клапана.
Насос и клапан питаются только от `12 В`. Пин `3.3V` можно использовать для
датчика, если конкретный модуль `XGZP6847A` рассчитан на питание `3.3 В`.

Если используется MOSFET `IRLZ44N` в корпусе TO-220, то при взгляде на корпус
спереди, надписью к себе и ножками вниз, обычно распиновка такая:

```text
1 - gate
2 - drain
3 - source
```

Металлическая пластина корпуса обычно тоже соединена с `drain`. Перед монтажом
обязательно проверьте datasheet именно купленного MOSFET, потому что у разных
корпусов и аналогов распиновка может отличаться.

### Защитные диоды

Насос и электромагнитный клапан могут давать выброс напряжения при выключении.
Чтобы этот выброс не повредил MOSFET и ESP32, параллельно насосу и клапану
ставятся защитные диоды.

Для насоса:

```text
катод диода, сторона с полоской -> pump+ / +12 В
анод диода                     -> pump- / MOSFET drain
```

Для клапана:

```text
катод диода, сторона с полоской -> valve+ / +12 В
анод диода                     -> valve- / MOSFET drain
```

Важно не перепутать направление диода. Если поставить его наоборот, он замкнет
питание при включении насоса или клапана.

### Питание и силовая часть

Понадобятся:

- блок питания 12 В с запасом по току;
- понижающий преобразователь 12 В -> 5 В;
- два logic-level MOSFET для насоса и клапана;
- защитные диоды;
- резисторы на затворы.

Примеры:

- LM2596 buck converter 12 В -> 5 В:
  https://chipster.ru/catalog/arduino-and-modules/supply-modules/4120.html
- IRLZ44N MOSFET:
  https://chipster.ru/catalog/active-components/transistors/field-effect-transistor/280.html
- 1N5819 diode:
  https://tmelectronics.ru/product/1N5819/

MOSFET лучше выбирать logic-level, чтобы он уверенно открывался от 3.3 В GPIO
ESP32.

Для каждого MOSFET нужны два резистора:

```text
100-220 Ohm, 0.25 Вт - между GPIO ESP32 и gate MOSFET
10 kOhm, 0.25 Вт     - между gate MOSFET и GND
```

На два канала управления, насос и клапан, нужно минимум:

```text
2 x MOSFET logic-level N-channel
2 x резистор 100-220 Ohm
2 x резистор 10 kOhm
2 x защитный диод
```

Резисторы можно покупать как отдельными номиналами, так и набором резисторов
для Arduino/макетирования. В поиске удобно использовать такие запросы:

```text
резистор 220 Ом 0.25 Вт
резистор 10 кОм 0.25 Вт
набор резисторов Arduino 0.25 Вт
```

MOSFET ищите как:

```text
IRLZ44N
IRLZ44NPBF
logic-level N-channel MOSFET TO-220
N-канальный MOSFET logic level
```

Важно не заменить `IRLZ44N` на `IRFZ44N` без проверки. Названия похожи, но
`IRFZ44N` обычно хуже подходит для прямого управления от `3.3 В` GPIO ESP32.

Для сборки прототипа также полезны:

```text
breadboard / макетная плата
провода Dupont
винтовые клеммы или клеммная колодка
перфоплата, если схема будет паяться
```

## Управление насосом и клапаном

Минимальный набор GPIO:

```text
PUMP_GPIO  -> MOSFET насоса
VALVE_GPIO -> MOSFET клапана
```

Рекомендуемая логика:

```text
1. Закрыть клапан.
2. Включить насос.
3. Следить за давлением по XGZP6847A.
4. При достижении целевого давления выключить насос.
5. Открывать клапан короткими импульсами или держать открытым через дроссель.
6. Поддерживать скорость падения примерно 2-3 mmHg/s.
7. Сохранять давление во время плавного сброса.
8. После падения ниже 40 mmHg полностью открыть клапан.
```

Начальные целевые значения для прототипа:

- стартовое давление: `160-180 mmHg`;
- программный аварийный лимит: `200-220 mmHg`;
- полный сброс: ниже `40 mmHg`;
- частота измерения давления: желательно `100 Hz` или выше.

Для первой версии можно сделать простую схему:

- насос включен до `170 mmHg`;
- насос выключен;
- клапан открыт через пневмодроссель;
- ESP32 просто записывает кривую давления.

После этого можно добавлять более умное PWM-управление клапаном.

## Алгоритм измерения

Обычный автоматический тонометр использует осциллометрический метод:

1. Манжета накачивается выше предполагаемого систолического давления.
2. Воздух плавно сбрасывается.
3. Датчик давления видит общий спад давления и малые пульсовые колебания.
4. Из колебаний строится осциллометрическая кривая.
5. Максимум кривой соответствует приблизительному `MAP`.
6. `SYS` и `DIA` оцениваются по эмпирическим коэффициентам от максимума.

На первом этапе необязательно сразу вычислять `SYS/DIA`. Полезнее сначала
получить качественную кривую:

- давление должно плавно падать;
- на кривой должны быть видны пульсовые волны;
- данные не должны теряться при BLE/SD/WiFi;
- показания должны совпадать с манометром после калибровки.

## Калибровка

Стрелочный манометр из текущей схемы полезно оставить как эталон для отладки.

Минимальная калибровка:

```text
0 mmHg   -> значение датчика при открытой системе
100 mmHg -> значение датчика по стрелочному манометру
150 mmHg -> значение датчика по стрелочному манометру
200 mmHg -> значение датчика по стрелочному манометру, только на стенде
```

После этого нужно проверить:

- нет ли утечек воздуха;
- совпадает ли давление при росте и при сбросе;
- не уходит ли ноль после нескольких измерений;
- не слишком ли шумит датчик.

## Безопасность

Обязательные меры:

- ручной механический сброс воздуха;
- программное отключение насоса при превышении лимита;
- полный сброс при ошибке датчика;
- полный сброс при зависании цикла измерения;
- таймаут накачки;
- таймаут всего измерения;
- запрет на повторную накачку, если давление не сброшено;
- тестирование без человека до первых реальных измерений.

Пример аварийной логики:

```text
if pressure > 220 mmHg:
    pump off
    valve open

if pump is on longer than 30 seconds:
    pump off
    valve open

if sensor value is invalid:
    pump off
    valve open

if measurement time > 180 seconds:
    pump off
    valve open
```

## Рекомендуемый порядок сборки

1. Собрать пневматику без электроники: манжета, насос, клапан, дроссель,
   манометр.
2. Проверить герметичность.
3. Подключить `XGZP6847A` и сравнить показания со стрелочным манометром.
4. Подключить насос через MOSFET.
5. Подключить клапан через MOSFET.
6. Написать простую прошивку: накачать до `160 mmHg`, сбросить, записать кривую.
7. Добавить аварийные ограничения.
8. Добавить запись данных в текущий BLE-протокол.
9. Добавить расчет `SYS/DIA` после получения стабильных графиков.

## Что можно реализовать в прошивке датчика

Новые состояния:

```text
IDLE
PUMPING
SETTLING
DEFLATING
COMPLETE
ERROR_DUMP
```

Переходы:

```text
IDLE -> PUMPING
PUMPING -> SETTLING, когда давление достигло цели
SETTLING -> DEFLATING через короткую паузу
DEFLATING -> COMPLETE, когда давление ниже 40 mmHg
любой режим -> ERROR_DUMP при аварии
```

В `DEFLATING` нужно сохранять массив давления. Именно этот массив потом
отправляется на хаб по текущему BLE-контракту:

```text
H1S;p;mmHg;sampleRate;schema
H1D;index;value
H1E;sampleCount
```
